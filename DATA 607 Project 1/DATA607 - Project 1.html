pre_Opp_Avg <- numeric(nrow(Chess_Data))

Chess_Data <- Chess_Data %>%
  mutate(across(c(Pre_Rnk, Rnd1_Num, Rnd2_Num , Rnd3_Num, Rnd4_Num, Rnd5_Num, Rnd6_Num, Rnd7_Num), as.numeric))

  #Reading the opponent's pair number.
  x1 <- Chess_Data$Rnd1_Num[n]
  x2 <- Chess_Data$Rnd2_Num[n]
  x3 <- Chess_Data$Rnd3_Num[n]
  x4 <- Chess_Data$Rnd4_Num[n]
  x5 <- Chess_Data$Rnd5_Num[n]
  x6 <- Chess_Data$Rnd6_Num[n]
  x7 <- Chess_Data$Rnd7_Num[n]
  
  #Use their pair number to find their ranking. Essentially a VLOOKUP. 
  v1 <- Chess_Data$Pre_Rnk[x1]
  v2 <- Chess_Data$Pre_Rnk[x2]
  v3 <- Chess_Data$Pre_Rnk[x3]
  v4 <- Chess_Data$Pre_Rnk[x4]
  v5 <- Chess_Data$Pre_Rnk[x5]
  v6 <- Chess_Data$Pre_Rnk[x6]
  v7 <- Chess_Data$Pre_Rnk[x7]
  
  #Combine opponents rankings into a vector. 
  opp_ratings <- c(v1, v2, v3, v4, v5, v6, v7)
  
  #Use the na.omit() function to drop unplayed matches (NA values). 
  clean_ratings <- na.omit(opp_ratings)
  
  # Calculate average opponent group ranking and round to the nearest whole number. 
  pre_Opp_Avg[n] <- round(sum(clean_ratings) / length(clean_ratings))
}

Conclusion

This exercise was a great test of my data tidying skills.

One of my key takeaways is the importance of carefully evaluating data import options before diving into wrangling. When I initially used read_table() on df_2, the output seemed “good enough”—not imported particularly well, but workable enough to manage the tidying process. However, after using read_delim() on df_1, I realized it would have provided a much cleaner, more consistent approach for both datasets. Moving forward, I will test multiple import functions up front to identify the best fit for the raw data structure before writing downstream code.

Looking ahead, I also see opportunities to refactor the code by leveraging additional tidyverse pipelines and consolidating the current multi-chunk workflow into a more streamlined, cohesive final script.
