Capability 1: Converting Characters to Numbers in Column 6 with Mutate

Dplyr is a Tidyverse package in R for data manipulation designed to make working with data frames and tibbles fast, readable, and intuitive. Part of the tidyverse suite, it provides a consistent set of function “verbs” that translate your data analysis thoughts directly into code.

Mutate() is a function in the dplyr package is used to create, modify, or delete columns in a data frame. It applies a transformation to your data while keeping the total number of rows intact and preserving all other existing columns

Example

# In this chunk, we will use the mutate function to convert latitude into a numeric column. From the original CSV data, longitude is automatically imported as numeric but latitude comes in as a character. 

bigfoot <- bigfoot %>%
  mutate(across(latitude, as.numeric))

Capability 3: Cleaning Column 5 with Lubridate

Lubridate is a Tidyverse package that makes it easier to work with dates and times in R. As of the latest tidyverse release, lubridate is part of core tidyverse.

ymd_hms() is a core function in the R package lubridate designed to parse character or numeric vectors into POSIXct date-time objects.

Example

# Load the bfro_locations.csv file

bigfoot <- bigfoot %>% 
  mutate(timestamp_dttm = ymd_hms(timestamp))
